# 加班费测算填列

只填写测算表里最左边的「实际加班数」和「实际夜班数」。日均加班费、夜班费、余额、上报加班费等公式已经在表里，不要改。

打卡表上的「夜班」「加班」须已经算好。还没有时，先用 punch-attendance，再运行本 skill。

## 先确认月份

测算簿里每个月一张表。用户没说填哪个月，就先问，不要自己挑。

每人夜班最多 20 个。平均加班费用该表「平均加班费」单元格里的现成公式反算，不要改成固定除数，也不要用旁边另写的夜班个数代替公式里的额度。

## 计算

```bash
python scripts/fill_overtime_pay.py "<测算表.xlsx>" --punch "<打卡表.xlsx>" --sheet "2026.9月"
```

- `--sheet`：月份表名称，必填。
- `--punch-sheet`：打卡簿里有多张带「夜班」「加班」的表时才需要。
- `--cap`：每人夜班上限，默认 20。
- 依赖：`openpyxl`

脚本按姓名对应（忽略姓名里的空格）。测算表上有人但打卡表没有，就停下来，不要留空。

文件被占用时，另存为同目录下的 `*_已填写.xlsx`。

## 回复

列出每个人的实际加班数、实际夜班数，以及脚本算出的平均加班费。某一项为 0 也要写出来。说明用的是哪张月表、夜班上限，以及公式里的夜班额度。
