# 打卡三列计算

只计算并填写已有表头「夜班」「加班」「出勤天数」的那一张表。不从另一份工作簿补录打卡。

## 先确认例外日期

周末默认算加班。下面两类日期没有默认值，用户没说就先问一次，说了就直接用：

- 哪些日子虽然是周末，但按正常上班，不计加班
- 哪些日子虽然是工作日，但仍算加班

例子（只说明格式，不是每次的默认答案）：2026-09-20 是周日但正常上班；2026-09-25 中秋节是工作日但仍算加班。

有多张表都带这三列，或一张都没有时，先停下来问要写哪一张，不要自己加表头。

## 计算

运行本 skill 目录下的脚本，不要手算：

```bash
python scripts/fill_attendance.py "<workbook.xlsx>" --normal-days 2026-09-20 --overtime-days 2026-09-25
```

- `--normal-days`：正常上班、不计加班的日期，可重复或用逗号分隔。没有就省略。
- `--overtime-days`：工作日但仍算加班的日期，可重复或用逗号分隔。没有就省略。
- 指定工作表：`--sheet "打卡时间 (2)"`
- 依赖：`openpyxl`

脚本会写入原文件。文件被占用时，另存为同目录下的 `*_已填写.xlsx`，并把新路径打出来。

日期从标题「统计日期：YYYY-MM-DD 至 YYYY-MM-DD」的起始日对齐，表头行上、三列结果左边的每一列为一天。表头可以是日号、`六`/`日` 或节日名。列数比标题截止日期更多时，多出的列按后续日历日继续算，并在回复里说明。

## 回复

列出脚本打印的每个人的夜班、加班、出勤天数，以及实际采用的例外日期。某一项为 0 也要写出来。
